# Oracle golden generation

Run from the repository root.

```bash
Rscript tools/oracle/ols.R
Rscript tools/oracle/logit.R
Rscript tools/oracle/probit.R
Rscript tools/oracle/poisson.R
Rscript tools/oracle/survey_glm.R
```

Outputs land in `tests/oracle/golden/`. Regenerating a golden changes every
stochastic result and must be recorded in `notes/061126_legacy_defect_ledger.md`
with the reason and the case ids affected.

`tests/oracle/data/oracle_main.csv` is generated by
`python tests/oracle/_datasets.py`. Its seed and `n` are frozen after R1.
